About CRX3

Understanding the purpose and capabilities of this security tool

CRX3 is a fork of Hydra-ESP (originally by SameerAlSahab, itself built on risinek's ESP32 Wi-Fi penetration tool) that transforms the ESP32 into a versatile Wi-Fi penetration testing device. This fork's changes — adjustable deauth intensity, a larger beacon spam capacity, and several bug fixes to the Evil Twin / stop-attack flow — were made by LuizFilipe89 with the help of Claude Sonnet (Anthropic), by someone with no prior programming experience. The whole codebase is 100% open source under GPL-3.0.


The project emphasizes responsible use and education, with built-in safeguards to prevent misuse. CRX3 is designed for:

  • Security researchers testing their own networks
  • Educational demonstrations of Wi-Fi vulnerabilities
  • Developing and testing network security protocols
  • Understanding wireless security mechanisms

Key Features

Powerful capabilities packed into an affordable ESP32 device

Wi-Fi Deauthentication

Normal, BSSID Clone, Multi-Clone, or Targeted-Client methods, with adjustable intensity up to 50 frames/burst and up to 16 simultaneous targets.

WPA Handshake Capture

Captures the WPA2 4-way handshake as .pcap / .hccapx, ready for offline auditing with Hashcat or aircrack-ng.

Beacon Spam

Flood the area with up to 200 fake access points — common names, random strings, Rick Roll, or security-themed.

Evil Twin

Open clone + deauth + captive portal password capture, with a custom-SSID rogue mode and custom portal upload.

Deauth Attack Detector

Monitors the air in promiscuous mode and alerts when a deauthentication flood is detected against nearby networks.

Bilingual Web Interface

Control everything from an intuitive web UI at 192.168.4.1, in English or Portuguese (BR), from any device.

Network Printer Attack (in development)

Scans a joined network for open printers and sends a raw print job. Present in the UI, still being refined.

ESP32 Compatibility

Designed specifically for ESP32 Devkit V1 and compatible development boards, with optional SSD1306 OLED display support.

Legal & Ethical Use

Understanding the boundaries of responsible security testing

Important Legal Disclaimer

CRX3 is developed strictly for educational purposes and authorized security testing. Unauthorized use against networks or devices you do not own is illegal in most jurisdictions.


⚠️ Always obtain explicit written consent before testing any network that is not your own.


Key legal frameworks to be aware of:

  • Computer Fraud and Abuse Act (CFAA) - United States
  • Computer Misuse Act - United Kingdom
  • EU Cybercrime Directive - European Union
  • Telecommunications Regulations - Various countries

The entire codebase — including the attack modules — is 100% open source (GPL-3.0) and available in the repository for anyone to read, learn from, and audit. The authors, both of the original project and of this fork, accept no liability for misuse or any damage resulting from it. You are solely responsible for how you use this software.

Installation Guide

Get CRX3 up and running on your ESP32 device

1

Hardware Requirements

You'll need an ESP32 Devkit V1 (or compatible board) and a USB cable for flashing.

2

Download Firmware

Get the latest firmware binaries from the GitHub releases page:

Download Releases
3

Flash Firmware

Use ESP32 Flash Download Tool or esptool.py to flash the firmware:

# Using esptool.py
esptool.py --chip esp32 -p COM3 -b 460800 write_flash \
  --flash_mode dio --flash_freq 80m --flash_size detect \
  0x1000  bootloader.bin \
  0x8000  partition-table.bin \
  0x10000 projecthydra-32.bin \
  0x190000 storage.bin
4

Connect & Access

After flashing, connect to the crx3 Wi-Fi access point and navigate to the web interface at 192.168.4.1.
